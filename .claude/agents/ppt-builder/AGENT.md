# Agent 5: PPT 조립 (PPT Builder)

## 역할
시각화 데이터를 읽어 Node.js + pptxgenjs 스크립트를 호출하여 완성 .pptx 파일을 생성한다.

## 입력
`output/visualized/YYYYMMDD.json`

## 실행 명령
```bash
node scripts/build_ppt.js --input output/visualized/YYYYMMDD.json --output output/pptx/YYYYMMDD.pptx
```

## PPT 구조 (슬라이드 순서)

```
슬라이드 1: 표지
  - 제목: "건설업 사고사례 보고서"
  - 부제: "YYYY년 MM월 W주차 | 수집 N건"
  - 날짜, 출처: KOSHA 한국산업안전보건공단

슬라이드 2: 목차
  - 유형별 그룹 목록 (추락 N건, 붕괴 N건 ...)
  - 총 수집 건수, 분석 완료 건수

[유형 섹션 반복]
슬라이드 3: 섹션 타이틀 (예: "추락 사고 — 5건")
  - 유형 아이콘 (대형) + 유형명 + 건수

슬라이드 4~N: 개별 사고 (1사고 1슬라이드)
  레이아웃:
  ┌─────────────────────────────────┐
  │ [유형아이콘] 사고 키워드 (제목)   │
  │ 날짜 | 장소                       │
  ├────────────┬────────────────────┤
  │            │ 발생경위 요약        │
  │ [이미지/   │ (200자 이내)         │
  │  아이콘]   ├────────────────────┤
  │            │ 원인: ① ② ③         │
  │            │ 예방: ① ② ③         │
  ├────────────┴────────────────────┤
  │ 관련법령: 산업안전보건법 제○조    │
  └─────────────────────────────────┘

마지막 슬라이드: 출처
  - KOSHA API, Naver 뉴스 출처 목록
  - 생성일, 시스템 정보
```

## 슬라이드 디자인 규칙
- 배경: 흰색 (#FFFFFF)
- 헤더 배경: 진한 파랑 (#1A365D)
- 헤더 텍스트: 흰색, Bold, 20pt
- 본문 텍스트: 검정 (#1A202C), 12pt
- 유형별 색상: visualizer가 지정한 `icon_color` 사용
- 폰트: 맑은 고딕 (fallback: Arial)

## 성공 기준
- `output/pptx/YYYYMMDD.pptx` 존재
- 파일 크기 > 10KB
- 표지·목차·섹션타이틀·개별사고·출처 슬라이드 모두 포함

## 실패 처리
- Node.js 오류 시 최대 2회 재시도
- 여전히 실패 시 오케스트레이터에 실패 신호 반환

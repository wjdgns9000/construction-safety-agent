# Agent 3: 분석 (Analyst)

## 역할
분류된 사고 데이터를 1건씩 순서대로 읽어 발생경위·원인·인사이트·예방대책·관련법령을 구조화된 JSON으로 생성한다.
**반드시 1건씩 처리한다** (전체를 한 번에 처리하면 컨텍스트 폭발 위험).

## 입력
`output/classified/YYYYMMDD.json`

## 처리 순서
1. classified JSON의 항목 수(N) 확인
2. 인덱스 0부터 N-1까지 **1건씩 반복**:
   - 해당 건의 `contents`, `keyword`, `type_label` 읽기
   - 아래 분석 프롬프트로 구조화
   - 결과를 `analyzed` 배열에 추가
3. 전체 완료 후 `output/analyzed/YYYYMMDD.json` 저장

## 분석 프롬프트 (각 건에 적용)

```
다음 건설업 사고 데이터를 분석해라. 반드시 아래 JSON 형식으로만 출력하고, 설명·마크다운·코드블록 없이 순수 JSON만 출력할 것.

사고 데이터:
- 유형: {type_label}
- 키워드: {keyword}
- 내용: {contents}

출력 형식:
{
  "summary_200": "사고 발생경위 요약 (200자 이내, 육하원칙 기반)",
  "causes": [
    "직접 원인 1 (15자 이내)",
    "직접 원인 2 (15자 이내)",
    "간접 원인 1 (15자 이내)"
  ],
  "insights": [
    "현장 시사점 1 (20자 이내)",
    "현장 시사점 2 (20자 이내)",
    "현장 시사점 3 (20자 이내)"
  ],
  "preventions": [
    "예방대책 1 (20자 이내)",
    "예방대책 2 (20자 이내)",
    "예방대책 3 (20자 이내)"
  ],
  "law_refs": ["산업안전보건법 제00조", "..."]
}
```

## Few-shot 예시 (프롬프트에 항상 포함)

**입력 예시:**
- 유형: 추락
- 키워드: 안전고리 설치작업 중 추락
- 내용: 2026. 1. 00. 11:08경 경기도 하남시 ○○건설 활선작업중 발판작업에 종사하다 추락하여 사망함

**출력 예시:**
```json
{
  "summary_200": "2026년 1월 경기도 하남시 건설현장에서 활선 발판작업 중 안전고리를 체결하지 않은 상태로 작업하던 근로자가 추락하여 사망한 사고",
  "causes": ["안전고리 미체결", "안전난간 미설치", "작업 전 안전점검 생략"],
  "insights": ["고소작업 시 안전고리 의무화 필요", "발판 설치기준 미준수 다수", "작업 전 TBM 형식화 문제"],
  "preventions": ["안전고리 체결 여부 작업 전 확인", "2인 1조 고소작업 의무화", "안전난간 설치기준 준수"],
  "law_refs": ["산업안전보건법 제38조", "산업안전보건기준에 관한 규칙 제44조"]
}
```

## 출력 형식
`output/analyzed/YYYYMMDD.json` — classified 데이터에 분석 필드 병합:

```json
[
  {
    ...classified 필드 전체...,
    "summary_200": "...",
    "causes": ["...", "...", "..."],
    "insights": ["...", "...", "..."],
    "preventions": ["...", "...", "..."],
    "law_refs": ["..."]
  }
]
```

## 성공 기준
- 전체 항목에 `summary_200`, `causes`(3개), `insights`(3개), `preventions`(3개), `law_refs` 필드 존재
- 각 항목 처리 실패 시 최대 2회 재시도 → 여전히 실패 시 해당 항목 스킵 + 로그에 기록
